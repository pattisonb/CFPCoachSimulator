# Pocket College Football: New UI Plan

The React rewrite of the game's front end (`ui/`, branch `new-ui`). This file is the source of truth for
what the new UI has, where each old screen goes, and what was decided. **Update it with every change.**

- The old UI and its full screen-by-screen map: `web/`, and the "CFP Coach Simulator Site Map" artifact
  (every old page, view, sub-view and popup with its URL).
- The game itself (Python: `app/`, `engine/`, `sim/`, `coach_career/`) does not change.

## Name and Nav

- The game is called **Pocket College Football** (was "CFP Coach Simulator").
- The header has one nav item: **Play** (was "Coach Career"). Nothing else gets a top-level nav item for now.
- The header's dark side holds only the light/dark toggle (a Phosphor sun/moon icon).

## Routes

`src/router.ts` maps the path to a page (under `ROOT`, the folder the app is opened from). Every screen below is planned
unless its status says otherwise.

### How the Moved Screens Are Reached

- **Your Coach (`/coach/edit`)** is no longer a page in the nav. It shows up:
  - while starting a new career from Play (create a coach, or pick one), and
  - mid-career, when you choose to edit your coach.
- **Custom Programs (`/program/edit`)** is no longer a page in the nav. It shows up:
  - while starting a new career from Play, as an option to make a custom program, and
  - later, as a God Mode option (not now).
- **`/program`** (a team overview) is an idea only. Tabled until we know where it fits in the new-game flow.

## The Game (`/play`): Current State

`src/pages/Game/` with the `GameNav` sidebar (`src/components/GameNav/`); the sections are listed in `src/sections.ts`.
Its own layout: no site header. Address: `/play?id=<season>&section=<key>`. Reached two ways: Your Coach opened for a
team, whose Confirm and Play saves the coach, starts a Coach Career (`POST /api/season` with the team and coach) and
opens it; or a saved season's card under Load Season. Picking a section rewrites the address in place (the rest kept),
so Back leaves the game. A section has no title row (the sidebar names it): its screen fills the space under the
top row and fades in as it opens. The strip's tiles and the coach card share one height and bottom edge.

The sidebar has three modes, like Notion's, remembered by this browser (`cfp.gameNav.mode`, `src/navMode.ts`): open
(Minimize and Hide at the top right), minimized to a rail of icons (names as tooltips; hovering the logo shows
Expand), and hidden (the pointer at the left edge floats it back over the page, with Keep Sidebar Open; the page shows
an Open button at the start of the top row). ⌘\\ / Ctrl+\\ hides and shows it.

## Conventions

- Each component or page is a folder with `index.tsx`, `index.css` and `messages.ts` (all visible text).
- One palette that follows the theme (no fixed dark panel); colors are Notion's neutrals in both themes. Colors, type, spacing and sizes come from `src/globals.css`
  (under 100 lines); fonts from `src/fonts.css`,
  files in `web/fonts/`. Space Mono only.
- Icons: Phosphor (`@phosphor-icons/react`).
- Shared pieces: `EditorPage` for any editor page (sidebar plus main), `FolderTabs` for tabbed panels, `Field` for form
  controls, `useListPopover` for searchable pickers. Reach for these before writing page CSS.
- No Tailwind. CSS class names are `block__element--modifier`.
- Phones (windows narrower than 768 px, `MIN_WIDTH` in `src/viewport.ts`) get the Mobile Not Supported page for every
  address; there is no phone layout.
- Sizes in `px` only (plus `%`, and `vh`/`vw` inside the `clamp()` scales); no `em`, `rem` or `ch`. Stylelint enforces it.
- `npm run check` (Prettier, Stylelint, TypeScript) passes before every commit.
- Copy follows the repo's `CLAUDE.md`: Title Case labels, sentence-case sentences, American spelling.
